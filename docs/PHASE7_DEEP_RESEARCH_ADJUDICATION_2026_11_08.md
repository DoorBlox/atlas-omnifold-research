## Claim-by-claim adjudication

| Deep Research claim | Assessment | Corrected interpretation |
|---|---|---|
| Real-data compatibility inference requires justified calibration | **SUPPORTED AS PROJECT GATE** | G15 remains NO-GO. A strictly *model-conditional* test might be possible without physical retraining, but its null, covariance, calibration and interpretation require independent justification. Never present it as experimental frequentist coverage. |
| ATLAS guide categorically forbids unblinded p-values | **OVERSTATED** | Section 2 recommendation 5 addresses **unknown two-point nuisance correlation** assumptions and their pseudodata validation, not a blanket prohibition on every possible test. |
| Official fill_cov_matrix loops over 29 sources | **INCORRECT** | The helper computes Hessian outer-product sums over **supplied** shifts or sample covariance of **supplied** replicas with divisor **R−1**. The separate 1D corr_matrix assembles selected families. **29** is the project's frozen source count, not an official hardcoded loop count. |
| Paper 25 versus project 29 means four extra two-point variations | **INCORRECT** | The project **29 matrices = 25 systematic-labelled terms + 4 stochastic terms**: finite evaluation MC, data bootstrap, MC-training bootstrap, NN ensemble. DD and Sherpa are **inside the 25**, not four new extra terms. Exact one-to-one mapping of project systematic labels to ATLAS's published 25 still needs verification. |
| 25- and 29-source traces should match numerically | **INVALID CRITERION** | Paper 25 *systematic* terms and project 29 *total* covariance terms are not two implementations of one sum. The 1D pseudodata notebook selects **15 project-equivalent names** (4 stochastic + 11 systematic), omitting **14 systematic** names. Historical 15/29 trace shares: **55.89% real, 61.73% pseudo**. A difference is expected and must not be used to choose a 2D model. |
| Form a 2×2 covariance from fractional-shift outer products | **WRONG FOR NORMALIZED FOUR-CELL ESTIMAND** | A 2×2 table has **four cells**, thus a **4×4** covariance with an all-ones normalization null mode and generically rank 3. For raw counts h, total H, shape p=h/H, use J=(I−p 1ᵀ)/H. Signed raw-count shift d gives first-order C=(Jd)(Jd)ᵀ. Four independent count-bin nuisances give C=J diag(d_i²) Jᵀ. Direct unqualified fractional (d/h)(d/h)ᵀ is not this covariance. |
| DD and Sherpa should be uncorrelated between bins by default | **UNSUPPORTED AS UNIQUE CHOICE** | User Guide recommends **fully correlated by default**; four independent-bin alternatives are available for two-point sources **if validated on pseudodata**. Retain four pre-specified DD/Sherpa scenarios; never choose by real-data fit. |
| Factorized 2D Gaussian changes Sherpa diagnostics by roughly 1% | **MISATTRIBUTED** | Hypothetical factorized two-level-by-two-level extension of the 1D width rule is **numerically identity** here. The **0.708151% pseudo / 1.820378% real** changes came from **arbitrarily flattening four cells into 1D**, an ordering-dependent non-inferential stress example. No official 2D smoother is defined. |
| Real and pseudo samples can be considered independent for all uncertainty calculations | **OVERGENERALIZED** | In **real unfolded vs nominal-generator**, the two weight columns share the **same event support**, so finite-MC covariance must include paired mixed moments. **Pseudo unfolded vs independent known truth** is a distinct comparator. Sample independence does not eliminate within-comparison covariance. |
| Matching NN/bootstrap seeds accounts for all training dependence | **UNVERIFIED** | Shared seeds alone do not establish cross-covariance or account for training-systematic dependence. Released replicas support conditional fixed-weight diagnostics, not proof of full-retraining coverage. |
| Bootstrap sample covariance uses R−1 | **VERIFIED WITH QUALIFICATION** | Real/pseudo data bootstrap counts **100/25**; MC-training **25/25**. NN ensemble covariance is separately divided by **R=100** to estimate ensemble-mean uncertainty. Correct source-wise denominators and estimands must not be conflated. |
| Bootstrapping released pseudo weights yields independent full pseudo-experiments | **FALSE EQUIVALENCE** | Resampling one already-unfolded sample gives **conditional fixed-weight** sensitivity, not repeated detector-level samples independently unfolded/retrained. No publicly accessible full-unfolding pseudo-experiment ensemble or original training checkpoints is **verified by the evidence reviewed**. Lack of a verified link does not prove nonexistence. |
| χ² statistics on pseudodata should be uniform | **STATISTIC CONFUSION** | Under a correctly specified fixed Gaussian rank-three null, the quadratic has a **chi-square(3)** distribution; **calibrated continuous null p-values** are uniform. Plug-in finite-replica covariance changes the null reference. Existing 5k Gaussian and 10k hybrid toys are **assumed-model sensitivity**, not experimental coverage. |
| If real p<0.05, require equally extreme pseudo outcomes ≤5% | **CIRCULAR/POST-HOC** | A p-value is itself a null tail probability. Pre-specify statistic, null, reference and calibration **before** inspecting the real residual. Validate type-I error under independent null pseudo-experiments with Monte Carlo uncertainty. Never switch methods based on real-data fit. |

## Minimum candidate test protocol — proposal, not GO

1. **Fix estimand and reference:** LL,LH,HL,HH; real unfolded versus nominal generator, and pseudo unfolded versus independent known truth. A 3×4 contrast matrix removes the normalization null direction; positive-definite 3×3 contrast covariance is necessary but not sufficient for inference.
2. **Fix covariance:** Signed four-cell shifts with correct normalization. Include documented stochastic components and 2D systematic family selection. Real comparison uses paired finite-evaluation-MC mixed moments; pseudo comparison includes independent truth finite-MC uncertainty. Reconcile source inclusion and cross-family dependencies **a priori**; the official 1D notebook's 15-family selection is a **stress case**, not an approved 2D prescription.
3. **Fix two-point assumptions:** Declare a physically justified primary DD/HV model and retain the four pre-specified alternatives as sensitivity checks. Fully correlated default is not automatically validated; four independent-bin nuisances are not uniformly "conservative" for every contrast. Never flatten a 2D table for 1D Sherpa smoothing.
4. **Fix null and scope:** Distinguish *conditional on released weights and an assumed source model* from *experimental repeated-sampling coverage*. Conditional Gaussian/hybrid toys can check only their own assumptions; a full experimental claim needs independent full-unfolding pseudo-experiments or a validated equivalent. The current released replica arrays are not such an ensemble.
5. **Freeze before real-data inference:** No real-data p-value or sigma until G5/G8/G12 pass for the declared scope. The already computed quadratic diagnostics are not calibrated p-values.
